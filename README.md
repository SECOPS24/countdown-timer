# Countdown Timer

A small web app that counts down to a target date and time, or for a set duration.

## Features

- Pick a target date and time, or enter a duration in hours, minutes, and seconds.
- Live countdown with start, pause, and reset controls.
- Shows days when the remaining time is more than a day.
- Light and dark mode follow the system setting.

## Run locally

```bash
npm start
```

Then open http://localhost:8080.

## Container

The included `Dockerfile` runs the app on port 8080 with no dependencies to install.
